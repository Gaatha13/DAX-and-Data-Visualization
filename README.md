# DAX-and-Data-Visualization

### Overview

This assignment focuses on data visualization and analysis using Microsoft Power BI. It involves creating clustered column, line, and pie charts to represent order placements, daily orders, and employee layoffs. It also includes creating calculated columns using DAX formulas and developing measures to calculate sums, total rows, valid records, missing values, minimum values, and maximum values. The assignment helps develop practical skills in data modeling, data visualization, and DAX calculations for effective data analysis.
